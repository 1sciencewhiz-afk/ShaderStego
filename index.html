ShaderStego

Hide encrypted text or any file inside a procedurally generated shader image.

ShaderStego hides an encrypted message or file inside the pixels of a generated image. Nobody looking at the PNG can tell it holds anything — only someone with the passphrase can get it back out.

Encoder & Decoder (standard)

The simplest way to hide something. Best for most uses.

  1. Open the Encoder tab. Type the text you want to hide, or attach a file instead (drag it onto the drop zone, or click it to browse — any file type works: PDF, ZIP, MP3, EXE, etc.).
  2. Enter a passphrase. Anyone extracting the data will need this exact passphrase.
  3. Click Generate Secure Image. A carrier image is generated, sized to fit your payload, with the encrypted data hidden in it.
  4. Click Download PNG and save the image. Share it however you like — the hidden data travels with the file.
  5. To get the data back out: open the Decoder tab, upload that PNG, enter the same passphrase, and click Decrypt Image. Text appears in the box below; a file offers a Download Extracted File button.

Adaptive Encoder & Decoder

A more advanced mode that hides data inside an existing photo or image instead of a generated one, concentrating changes in busy/textured areas rather than smooth ones (harder to detect) and stretching capacity further.

  1. Open the Adaptive Encoder tab. Upload a carrier image (a real photo works well) or click Generate procedural carrier for one.
  2. Leave Variance window and the two threshold sliders at their defaults unless you want to tune capacity — the Capacity Meter updates live and warns if your payload won't fit at the current settings.
  3. Enter your text or attach a file, plus a passphrase, then click Hide Data Adaptively and download the result, same as the standard Encoder.
  4. Decode it in the Adaptive Decoder tab the same way as the standard Decoder: upload the PNG, enter the passphrase, click Decrypt Image.

Good to know

  • Always download as PNG. Never re-save, re-compress, resize, or share the image through an app that re-encodes it (some chat apps do this automatically) — any of that destroys the hidden bits.
  • The passphrase must match exactly. There's no password reset — if you forget it, the data is unrecoverable.
  • Everything runs locally in your browser. Nothing is ever uploaded anywhere.
  • Images made with an older version of this app, or with the wrong mode's decoder, won't decode — the Encoder/Decoder and Adaptive Encoder/Decoder use different, incompatible formats, so use the matching pair.

Payloads are gzip-compressed before encryption to stretch capacity further.
